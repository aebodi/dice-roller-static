Yahtzee Dice Roller

Five six-sided dice, rolled fairly, every time.

How to Use

Yahtzee is played with five 6-sided dice. This application rolls all five dice for you and reports the result, so you can play without hunting for physical dice.

  1. The dice roll automatically when the page loads.
  2. Press Enter or click Roll Dice to throw all five dice again.
  3. Watch them tumble, then read each value below its heading; the totals update on every roll.

All result fields are read only — they are filled in by the program using randomly generated numbers between 1 and 6.
